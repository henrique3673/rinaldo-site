Rinaldo

Política de privacidade

Última atualização: 29 de setembro de 2026

Quem usa o Rinaldo

O Rinaldo é um assistente pessoal de uso privado. O único usuário é o próprio desenvolvedor, Henrique, que o executa no próprio computador. O aplicativo não é distribuído nem oferecido a outras pessoas.

Dados do Google acessados

Com a autorização do usuário, o Rinaldo acessa, na conta Google dele:

  • Gmail: ler, pesquisar, organizar, rascunhar e, após confirmação explícita, enviar e-mails;
  • Google Agenda: ver, criar, alterar e excluir compromissos;
  • Google Drive, Docs e Planilhas: pesquisar, ler, criar e editar arquivos;
  • Google Tarefas: ver, criar e concluir tarefas;
  • Contatos: consultar contatos.

Esses dados são usados apenas para as funções que o próprio usuário pede ou vê no painel do Rinaldo. Ações que enviam, compartilham ou apagam algo sempre pedem confirmação do usuário antes.

Onde os dados ficam

  • O Rinaldo não tem servidor próprio. Os dados ficam no computador do usuário.
  • Os tokens de acesso ao Google são guardados cifrados (Windows DPAPI).
  • Caches locais, como o resumo de e-mails e da agenda do painel, ficam na pasta de dados do aplicativo no mesmo computador.

Com quem os dados são compartilhados

Para responder a um pedido do usuário, o Rinaldo envia à API Claude, da Anthropic, somente o conteúdo necessário para aquele pedido (por exemplo, o texto de um e-mail que o usuário pediu para resumir). Esse processamento segue os termos comerciais e a política de privacidade da Anthropic.

Fora isso, os dados do Google:

  • não são vendidos;
  • não são usados para publicidade;
  • não são transferidos a outras pessoas ou empresas;
  • não são usados para desenvolver, melhorar ou treinar modelos de inteligência artificial ou aprendizado de máquina generalizados.

O uso e a transferência de informações recebidas das APIs do Google pelo Rinaldo seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Outros serviços

O clima vem do Open-Meteo (só a localização da cidade escolhida é enviada) e as notícias vêm de feeds RSS públicos. Nenhum dado do Google é enviado a esses serviços.

Retenção e exclusão

  • O acesso pode ser revogado a qualquer momento em myaccount.google.com/linkedapps.
  • Apagar a pasta de dados do Rinaldo no computador remove os tokens e os caches locais.
